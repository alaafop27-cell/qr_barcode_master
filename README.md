# QR & Barcode Master

Offline Flutter app: scan QR/barcodes, generate QR codes, keep a local history, Material 3 theming.

## Build the APK on GitHub (no Android Studio needed)
1. Create a GitHub repo and push this folder's contents (keep `.github/`, `lib/`, `tool/`, `pubspec.yaml`).
2. Open the **Actions** tab -> *Build Release APK* -> **Run workflow** (it also runs on every push to `main`).
3. When it finishes, download **QR-Barcode-Master-release-apk** from the run's *Artifacts* section.
   Pushing a tag like `v1.0.0` also attaches the APK to a GitHub Release.

The `android/` folder is generated by the workflow, so it is not stored in the repo.

## Plug in AdMob later (no code changes)
Ads are completely off until you add three **repository variables**
(*Settings -> Secrets and variables -> Actions -> Variables*):

| Variable | Example |
|---|---|
| `ADMOB_APP_ID` | `ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY` |
| `ADMOB_BANNER_ID` | `ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ` |
| `ADMOB_INTERSTITIAL_ID` | `ca-app-pub-XXXXXXXXXXXXXXXX/WWWWWWWWWW` |

Re-run the workflow and the banner (bottom of the app) and interstitial (every 4th action) turn on.
Details/alternatives are documented in `lib/core/ads/ad_config.dart`.
